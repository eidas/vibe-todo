# vibe-todo

React（CDN）で動くシンプルなToDoアプリです。入力したタスクはローカルストレージに保存され、ページを閉じても残ります。

## 使い方
1. 開発サーバーを立ち上げます。任意の静的サーバーでOKですが、Pythonがある場合は下記が簡単です。
   ```bash
   python -m http.server 5173
   ```
2. ブラウザで `http://localhost:5173` を開くとアプリが表示されます。
3. 入力欄にタスクを入力して **追加** ボタンを押すとリストに追加されます。
4. チェックボックスで完了/未完了を切り替えたり、✕ボタンで削除できます。
5. 「完了を一括削除」ボタンで完了済みタスクだけをまとめて消せます。
6. 上部のフィルター（すべて / 未完了 / 完了）で表示を切り替えられます。

## メモ
- 依存パッケージのインストールは不要です。`index.html` と `style.css` をそのまま配信すれば動作します。
- 初回表示時にローカルストレージへ自動保存が行われるので、シークレットモードなどストレージが無効な環境では保存されません。
